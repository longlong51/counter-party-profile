# 基金/证券交易与交易对手方知识库（100 条）

- 采集时间：2026-11-09（Asia/Shanghai）
- 采集方式：浏览器访问 + 官方页面/PDF 正文抽取
- 条数：**100 条**（唯一 ID，无重复标题）
- 采集窗口：以 **2026 年 5 月以来发布或生效的规则为主**，另保留少量仍然现行有效、且近半年内不会变动的基础制度（如登记结算、反洗钱、结算风险基金），已逐条核验其现行有效性；未收录任何已废止规则

- 结构化字段：`id / category / sub_category / title / content / key_points / source_name / doc_title / source_url / publish_date / effective_date / freshness / tags / counterparty_relevance`

## 使用建议

1. RAG 入库时建议按 `id` 作为文档主键，`category + sub_category` 作为元数据过滤字段。
2. `counterparty_relevance` 为「高」的 45 条（清算交收、违约处置、KYC、信用风险）可直接作为对手方画像报告的事实依据库。
3. 涉及具体比例/时限的数字（如 10% 巨额赎回、7 个工作日、9/百万分之几）在生成对外报告时应回链 `source_url` 复核。
